ZIP 包含全部接收目标、订阅、自定义设置、关键词规则、文章历史和全局配置。备份含聊天 ID 等私人信息，请妥善保管。

合并还原

按聊天 ID 和 RSS 地址合并。备份中的同名订阅与目标设置会覆盖当前设置，当前额外的订阅会保留。先校验和预览，再确认执行；执行前自动保留一份恢复备份。

数据库连接与 Web 密钥保持当前值。运行配置还原后以 config/web-restored.env 为准。
